In art, a study is a copy you make of a master's work to learn how it was made. These are studies of classic games, one system at a time. Each sketch pairs screenshots and narrative with the variables and code behind them — and ends with working code you can play.

It's made for the fun of it. It's for anyone curious about how these games were built. It honors the people who made them. And it tries to keep the games alive, rebuilt for the web.
